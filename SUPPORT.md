# Support

- **Documentation:** start at [`docs.zarishsphere`](https://github.com/zsdotcom/docs.zarishsphere)
- **Bugs / feature requests:** open an issue using the templates in this repo
- **General questions:** use GitHub Discussions on the relevant repository if enabled,
  otherwise open an issue with the "question" label
- **Security issues:** see [SECURITY.md](SECURITY.md) — do not use public issues

This is a solo-founder project with no dedicated support team. Response times are
best-effort.
